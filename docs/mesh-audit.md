# Ward mesh audit and Phase 1 repair record

8 September 2026. **Phase 1 is in progress; neither the whole mesh audit nor the district's visual target is complete.** The preceding task, “Add localized dirt and wear”, finished before this pass began. Its courtyard, canopy, posters, vegetation, routes and accepted reference remain in place.

The saved Unity scene was inventoried before repair: **917 intended active source instances, 770 unique source meshes and 1,401,874 source triangles**. These totals exclude hidden/rejected geometry and derived chunks, and are not visible-camera or multipass submission counts. No LODGroups were present. The full inventory also records inactive sources, primitives, chunks, materials, texture bindings, colliders and all nine actors.

See the [one-row-per-unique-mesh ledger](mesh-audit-assets.md), [instance inventory before](../unity/evidence/phase1/20260908/scene-audit.json), [inventory after](../unity/evidence/phase1/20260908/after-scene-audit.json), and [individual building tasks](../unity/evidence/phase1/20260908/building-ledger.json). Every mesh is accounted for in those data; that does not mean every mesh has received a close-up visual review. Unreviewed entries explicitly retain that status. Source-versus-import comparison, texel density, wireframes and complete front/back/roof review remain outstanding for the wider district.

## Reference and review boundaries

Finery follows the [accepted courtyard target](../refs/courtyard_20260908/accepted-target.png), with the existing doorway/porch and 1.8 m actor as scale references. The target is a direction for material/construction quality, not proof of native quality. The hall retains its accepted Meshy source identity while fixing scale. Vex retains the original ivory armour, dark undersuit/visor and cyan forehead mark. The tree uses its existing silhouette and root footprint; no wider city generation or lore changes occurred.

Native images, builds, preservation checks, measured performance and remaining defects are documented in the [dated Phase 1 evidence](../unity/evidence/phase1/20260908/README.md). The current source count is a cost measurement, never a substitute for the visual scores or real-input checks. The phase remains open until the wider character, tree and building work is reviewed.
