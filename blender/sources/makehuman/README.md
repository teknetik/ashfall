# MakeHuman source assets

Selected assets downloaded from the official MakeHuman Community asset packs
on 2026-09-07, for the user-authorized character replacement. Original files
are retained; `source-manifest.json` records source URLs and SHA-256 hashes.

- Human anatomy, macro targets, standard rig and weights: MakeHuman Community,
  supplied through MPFB 2.0.17. Graphical assets CC0; the add-on code is GPL.
- Skin, eyes and eyebrows: MakeHuman system assets, CC0.
- Aksel skin: Mindfront, CC0 in the Skins 02 pack. Only its normal map is used,
  at strength 0.22; the audition's bruised diffuse skin was rejected.
- Viking beard and moustache (audition only): RehmanPolanski, CC0.
- Sigmund beard: grinsegold, CC0 in the current official Bodyparts 05 pack.
  Its original file retains an older MakeClothes-generated AGPL3 header;
  the current pack manifest and asset-pack page explicitly list this asset
  under CC0. Both records are retained rather than rewriting source headers.
- Grump hair: Elvaerwyn, CC-BY; adapted in Blender by fitting to the colonist,
  reducing the crest and changing its colour. Credit must ship with the game.

The character's armour is original Blender geometry. Purchased assets have
not been used. This folder is authoring source; only tested GLBs and needed
textures belong in the runtime export.
