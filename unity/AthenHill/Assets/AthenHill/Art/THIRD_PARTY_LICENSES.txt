# Third-party asset credits and licences

## Current music — user-supplied

Dust of the Giants and Dust of Alshain were supplied by the user on 8 September
2026. The original MP3 files are preserved in Assets/AthenHill/Audio/Music.
No artist or licensing metadata was provided or inferred. These tracks replace
Hill at Dusk in the playable city.

## Athen Hill soundscape — ElevenLabs (effects and historical music)

"Hill at Dusk" instrumental music and twelve sound-effect assets were generated
for this project with ElevenLabs on 8 September 2026, using the project's account.
Music: music_v2. Sound effects: eleven_text_to_sound_v2. Original prompts describe
the colony setting and do not reference an existing soundtrack or artist.
The game uses edited, level-balanced versions with prepared loop boundaries.
Original responses, prompts and hashes are retained in
unity/staging/elevenlabs-audio/manifest.json and the adjacent source records.
Generated outputs are subject to the account's ElevenLabs terms.

These notices cover the sources used to author Athen Hill's replacement
colonist. Keep this notice with distributions containing the derived assets.
Original source files, pack metadata and file hashes are retained in the
repository under `blender/sources/`.

## Poly Haven texture contributors

- [Blue Metal Plate](https://polyhaven.com/a/blue_metal_plate): normal detail
  and diffuse-derived neutral wear for the olive armour. A source roughness
  map is retained, although the selected metal material uses constant roughness.
- [Fabric Leather 01](https://polyhaven.com/a/fabric_leather_01): normal and
  roughness detail for dark suit and gear materials.

Both are **CC0**, as stated in [Poly Haven's asset licence](https://polyhaven.com/license).
The project adjusts UV scale, normal strength and material response; the
metal diffuse is adapted into a neutral wear texture using Blender. Original
downloaded maps are preserved in the source archive.

## Meshy mission terminal

The mission-terminal model was generated for Athen Hill with Meshy Multi-Image
to 3D on 8 September 2026 from original project concept art. Meshy task and
generation settings are retained beside the source model in
`meshy/mission-terminal-v1/model/meshy-manifest.json`. The game imports the
textured GLB and uses three instances of that one asset.


Meshy salvage and civic rebuilding pass — 2026-09-08
Original reference sheets were generated for Athen Hill using OpenAI image generation; Relay Works reuses the project’s accepted reference sheet. Task IDs, input-view provenance, face counts and SHA-256 digests are recorded in meshy/salvage-20260908/manifest.json. Source FBX/GLB and textures are retained there. ## Meshy district rebuilding and yard mechanic — 2026-09-08

Seven original shop redesigns and a west gate arch module were generated using
Meshy 7 multi-image-to-3d from original OpenAI image-generation turnarounds. The
yard mechanic is a new original adult humanoid generated from three reference
views and rigged by Meshy, with its supplied walk/run motions. Unity imports it
as Humanoid. These are project-generated assets, with no extracted game models.
Task requests, reference provenance, FBX/GLB originals, source textures and SHA-256
digests are retained in meshy/district-20260908/manifest.json.
