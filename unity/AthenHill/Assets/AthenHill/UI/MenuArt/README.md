Original artwork generated with the built-in imagegen tool for the startup menu.

playable district. The original PNG is retained at its generated resolution;
StartupMenuArtImporter preserves aspect ratio and imports it up to 4096 pixels,
without mipmaps. The menu uses scale-and-crop to fill the window.

StartupMenu.uxml / StartupMenu.uss. This artwork supersedes no gameplay assets
or accepted environment references.
