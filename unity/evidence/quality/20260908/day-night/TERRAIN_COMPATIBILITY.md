# Terrain compatibility with the lighting clock · 9 September 2026

`DesertTerrain.shader` previously multiplied direct light by a fixed red-channel vertex shadow bake and blended distance haze toward a constant daylight beige. Rotating the sun left those noon shadows in place; night still had bright haze. Green-channel vertex ambient occlusion is separate and is preserved unchanged.

The clock now supplies two globals, owned and restored by `CityTimeOfDay`: `_AthenTerrainTime` (active flag and validity of the authored directional shadow bake) and `_AthenTerrainHazeScale` (RGB haze multiplier). No CityAtmosphere/wind globals, materials, geometry, scene references, graphics API or pipeline settings were changed.

At the captured authored sun direction, the old shadow multiplier and specular behavior remain unchanged, and the haze multiplier is exactly one. The red-channel directional bake fades out smoothly as the key direction changes between 3 and 18 degrees. It is fully disabled when solar visibility is zero, even if a night key happens to share the old direction. Light roll does not affect this test. As that bake retires, current URP main-light shadows fade in; the green-channel AO remains applied only to ambient geological cavity shading.

The live shadow path uses installed URP 17.6 `GetMainLight(TransformWorldToShadowCoord(positionWS), positionWS, half4(1,1,1,1))`. This includes shadow-distance fade and the package's current cascade/screen-space coordinate handling. Main-light and soft-shadow variants match the installed package keywords. No lightmap shadow mask is invented, and no baked directional value becomes a permanent AO value.

The haze multiplier is the current fog color relative to the captured authored fog, computed in linear light for this project's linear renderer. Thus each terrain material keeps its existing authored haze tint at noon but becomes cooler/darker with the clock. Gamma projects use gamma-space ratios; zero/invalid denominators remain finite. The output retains the existing depth/height haze density rather than changing visibility distance during this bounded fix.

Limits: this is distant backdrop terrain. It still has no ShadowCaster pass, and its authoring importer retains its existing shadow-casting-off setup. Outside the actual URP shadow distance, moving normal-based light and the preserved AO provide shading; this patch does not add expensive long-range terrain self-shadow maps. Native dawn/noon/night comparisons must assess that tradeoff. Nearby cast shadows can only come from renderers actually included in the active main-light shadow map. No native shader compilation, GPU measurement or visual sign-off is claimed here.

Four meaningful Edit Mode cases were added to `AthenHill.Tests.DayNightTests` (15 total parameterized results now expected): unchanged default/irrelevant roll, invalid noon shadows at dawn/night, stable default/zero haze channels, and darker/cooler night ratios in linear light. Runtime Editor/release and test-source temporary compilation passed with no errors or warnings. Root must execute the tests in Unity and inspect the actual shipping shader/native captures. Logs and source hashes are in `terrain-compatibility.json`.

Primary API verification was the installed package source: `ShaderLibrary/RealtimeLights.hlsl` (three-argument GetMainLight), `ShaderLibrary/Shadows.hlsl` (TransformWorldToShadowCoord, MainLightShadow and shadow-distance fade), and `Shaders/Lit.shader` (main/soft shadow keyword variants). No web or older Unity example was substituted for the installed implementation.

A separate actual integration defect was also fixed: the original installation report passed DayNightFrame's Unity structs directly to Newtonsoft, causing recursive Vector3.normalized serialization after the scene components/assets had already been created. `DayNightPass.ExportInstalledReport()` now validates the existing installation and writes the report with Unity-serialized fields converted to JToken; it performs no scene/material mutations. The integrating task must run this recovery method instead of rerunning Install.
