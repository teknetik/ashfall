## Unity → JSON developer-UI contract

`Assets/AthenHill/Data/Crafting/Export/ward-crafting.v1.json` is generated from the two real Unity catalog assets by `Assets/AthenHill/Editor/CraftingDataExporter.cs`, schema `ward-crafting/1`. Top-level fields: `schema`, `generated` (UTC, Unity version, source asset paths), `items`, `weapons`, `modifiers`, `stations`, `recipes`, `lootTables`, `enemies`, `encounters`, and `rules`. Item records include canonical IDs, tags, caps, trade flags, prices, starting quantities, and catalog index. Weapon state source remains `PlayerCombat.hasPistol`, not a tradable inventory entry. `ward-crafting.v1.vectors.json` uses schema `ward-crafting-vectors/1`: the `starter-craft-fit` case was executed through the real Unity `ShopModel` and `CraftingModel`; `seed1729-first-five-rolls` records actual Unity/.NET `System.Random(1729).NextDouble()` outputs. JS consumers must use vectors, not assume their PRNG matches .NET. The exporter validates recipe references and fixed tutorial capacity before writing. These files are generated, not manually invented examples.
