# Sign lettering fonts

- `NotoSans-Black.ttf`, `NotoSans-Bold.ttf` — Noto Sans (Google Fonts / Noto project), copied from the local
  Arch Linux `noto-fonts` package (`/usr/share/fonts/noto/`) on 30 Sep 2026. Licence: SIL Open Font License 1.1
  (package licence field `OFL-1.1-no-RFN`; full text https://openfontlicense.org). Used only to generate 3D sign
  letter meshes in Blender; the fonts are not shipped in the game build.
- The letters are compressed horizontally in the sign generator for a condensed industrial look.
