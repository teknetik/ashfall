# Quiet coating installation — staged 10 September 2026

`MetalCoatingPass.cs` is an Editor-only follow-on to `DoorFrontLitPass`. Root chooses a reviewed source revision explicitly. Nothing in these scripts marks the source or native game accepted. Candidate-v1 is rejected; candidate-v2 remains subject to source/composite critic review.

The exact source roster has 111 slot-0 assignments: FieldCoatedSteel37, FineryDoorCoatedSteel4, FineryLouvreCoatedSteel50 and ShutterSteel20. It clones four materials and shares two sets of three full-source4096 maps. On the twelve split door receivers it replaces only submesh0/material slot0; the existing unique front submesh1/material slot1 remains untouched. No meshes, UVs or transforms change in this pass. Bronze, kickplates, seals, stone and text are outside the roster.

The preserved BaseMap scales are0.1875,0.25,1,1 respectively, each producing the authored4m tile with its existing mesh UV density. MainTex scale/offset is also preserved. The twenty shutter meshes additionally validate every retained world position within0.00003m, because lip wear is physically registered. Source/material/meta hashes and the full source roster are strict live guards, rather than historical whole-scene locks. A legitimately changed target must be inspected and its contract deliberately revised; the helper will not silently broaden its scope.

Run in this order:

1. The exclusive live Blender operator authors and previews the chosen metal source revision. Review source appearance and the actual unique door-front composites before installation.
2. In that same session, run `package_metal_coating_v1.py` with explicit globals `COATING_SOURCE_REVISION='candidate-v2'`, `COATING_PACKAGE_REVISION='candidate-v2-coating-v1'`, `RUN_METAL_COATING_PACKAGE=True`. Use new names for further revisions. This file-only operation does not read/change the Blender scene or Unity. It copies authored BaseColor/Normal bytes exactly and packs the authored scalar maps into RGBA16: R=metallic, G/B=0, A=65535−roughness. It validates all six source readback checks, manifest/hash/schema, source dimensions and integer roundtrip. Original maps stay intact. Output appears in a new `metal-v4/<packageRevision>` folder.
3. Compose/review the unique door fronts with `compose_door_front_lit_v1.py`, then close Blender before reopening Unity on this host. Copy the latest staged `DoorFrontLitPass.cs`; its receipt now includes derivative mesh/meta hashes and material hashes. Call its `Inspect` and `Apply` with the explicit composite revision. The coating helper requires that completed receipt and confirms the front map bytes against the installed composite manifest.
4. Call `AthenHill.Editor.MetalCoatingPass.Inspect("candidate-v2-coating-v1", "candidate-v2-litfront-v1", "preflight-v1")`. Its third argument is a fresh evidence name. This performs no scene or Assets mutation; stale chunks may be recorded for inspection. The authored source revision must match the one used by the installed front composites.
5. Rebuild any currently stale source chunks, then call `MetalCoatingPass.Apply("candidate-v2-coating-v1", "candidate-v2-litfront-v1")`. Apply repeats the guards, requires a clean saved scene and mip limit0 for import validation, copies only new assets, snapshots unchanged components and all relevant source/importer hashes, shows sources, assigns slot0, rebuilds chunks, verifies preservation and saves. It creates `Assets/AthenHill/Art/ReferenceStreet/20260910/MetalCoating/<packageRevision>` and fresh `unity/evidence/reference-street/20260910/metal-coating-<packageRevision>` evidence. Before-scene and failure records are retained; a failure must be inspected/recovered before continuing.
6. Verify the saved/reopened scene and native build at matched door/shutter close-ups, midday and hour16 after reflection completion, and moving approaches. Judge normal direction, paint/bare/oxide response, wear registration, seams and temporal grain. Test affected gameplay and performance through the root's native qualification workflow.

Runtime import uses normal-map GL orientation without green flip, sRGB BaseColor, linear packed masks, trilinear repeat, anisotropy8, streaming mips and HQ compression. The exact16-bit claim applies to retained packed source PNGs; runtime compression still requires native review. This is a material pass with four cloned materials, not a new shader, mesh pass or generic grunge overlay.

`coating-staging-validation.json` records the exact roster/hash audit, successful C# compilation against the installed project and exhaustive scalar16-bit codec roundtrip. The original source images were not processed during that offline validation. Live packaging, Inspect/Apply and native acceptance remain pending.
