## Live Blender sequence

Run each script's text through the live Blender MCP; do not run background Blender. These scripts are staged and Python syntax checked, but their Blender API calls have not yet been executed.

1. `inspect_generator_v2_source.py` verifies retained source/reference hashes, imports exactly one detailed FBX mesh, preserves its geometry/UVs, and makes a uniform metric review fit. It writes `source-review-v1/source-topology-fit.json` and `generator-v2-source-review.blend` under the source folder. It refuses a previous output revision or a heavy existing Blender scene. Optional `GENERATOR_YAW_DEGREES` is 0/90/180/270; use 0 for the initial axis survey. Front/back semantics remain provisional until compared with references.
2. `render_generator_v2_review.py` renders one view per call. Set `GENERATOR_VIEW` to `front`, `back`, `left`, `right`, `top_oblique`, `grille_close`, `rear_panel_close` or `top_fittings_close`. First use `GENERATOR_VARIANT='source'`, `GENERATOR_RENDER_TAG='source'`. Inspect whole views before framing the close views. `GENERATOR_CAMERA_OVERRIDE` permits an explicit recorded position/target/type/framing correction; use identical values for each later source/near pair. Output names refuse overwrites.
3. Obtain an actual source/fit review. Reject fused/opening failures, floating hoses, warped frame members, unusable silhouettes or heavy directional highlights in the base map. The diagnostic counts are not acceptance. If accepted for derivation, set `GENERATOR_SOURCE_APPROVED=True` and run `prepare_generator_v2_near.py`.
4. The first proposed near experiment is **200,000 triangles**, adjustable with `GENERATOR_NEAR_TRIANGLES`. This is a comparison starting point, not a retired scene budget or an automatic quality threshold. It copies the detailed geometry, collapses only that derivative, preserves the full source, and saves `generator-v2-near-200000/generator-v2-near-before-rebake.blend` plus a topology report. It flattens the reviewed positive uniform transform into metric coordinates before future baking. No collider or Unity content is created.
5. Render both `source` and `near` using the same views and `GENERATOR_RENDER_TAG='shared-uv'`. Inspect tubing bends, grille/coil gaps, eyelet apertures and painted panel markings at their closest intended view. A low surface-distance error or additional triangles cannot accept collapsed mapping. Raise the near density, protect/re-author a local feature, or reject the derivative if silhouette/construction is damaged. Do not use a texture bake to conceal missing geometry.
6. If geometry passes but collapse moves UV detail into triangles or introduces seams, set `GENERATOR_NEAR_GEOMETRY_APPROVED=True` and run `prepare_generator_v2_rebake.py`. It creates new UV0 only on the near mesh. Start with metric cage extrusion 0.0015 m and max ray distance 0.006 m; explicitly revise these after checking thin grille/coil spacing and projection errors. The small gap between neighbouring parts may require a split/cage adjustment rather than longer global rays. The prior collapse scene remains recoverable.
7. Run `bake_generator_v2_channel.py` four separate times with `GENERATOR_BAKE_CHANNEL` set to `base_color`, `roughness`, `metallic`, `normal`. Each output is 4096², with a 24-pixel margin; original 2K scalar maps remain retained and are not described as newly acquired 4K detail. Color and scalar channels use selected-source emission projection, excluding scene lighting. The tangent GL+Y normal bake includes the detailed source surface and its original normal texture. Source shading restores even if a channel fails. Each completed channel retains its own report and Blender checkpoint.
8. `finish_generator_v2_rebake.py` binds all four completed near maps, exports an immutable metric FBX candidate and writes a runtime manifest. Re-render source and near at identical positions with tag `rebaked`; the near must use its own new UVs and maps. Compare front/back, grille, side pipes, markings and eyelet edges. Watch for cage misses, black seams and cross-part color/normal leaks. Source and native acceptance remain false until the actual respective reviews pass.

If the inherited-UV candidate passes the full material comparison, a rebake is unnecessary: export that accepted near geometry with copies of the original full source maps and a derivative manifest documenting the unchanged mapping. The staged bake path is for a demonstrated mapping defect. Do not run the rebake merely to claim more texture resolution.

## Diagnostic scope

`generator_v2_review_common.py` records triangle/vertex counts, finite coordinates, metric bounds, surface area, signed surface volume, degenerate triangles, raw indexed edge counts, UV layers and imported custom-normal presence. It separately analyses coincident vertices at a 10 µm grid to distinguish common UV splits from geometric boundaries and reports connected-component sizes/bounds. This diagnostic never welds or repairs the source. Grid equivalence can merge nearly coincident surfaces; it is not a watertightness certificate. Signed volume is meaningful as enclosed volume only for closed, consistently oriented components. Boundary counts need visual interpretation around intentional apertures, sheets and internal parts.

Matched views use fixed camera/light/exposure settings, AgX, no depth of field, 1400 × 1100 at 100% and 24 Cycles samples. Bake samples are 8. Actual selected compute device and Blender RSS/high-water/swap are recorded; these are authoring measurements, not native game performance. Each render is a separate call to keep long work observable and avoid concurrent GPU jobs.

`generator-v2-staging-checks.json` records syntax checks and pure numeric tests of the actual audit functions: an outward closed cube, open plane, two separated cubes, a closed cube with per-face UV splits and an inward cube. All passed, including raw-versus-coincident edge differences, connected components and signed-volume orientation. This does not execute or validate Blender APIs.
