## Fabric material handling

The existing URP Lit shader and original full-resolution imported textures are reused. UV0 is authored in metres / 0.4. `_BaseMap` scale 1/7 therefore produces a 2.8 m color tile; `_DetailAlbedoMap` scale 7 multiplies the already transformed base UV and restores the 0.4 m normal weave. `_DetailAlbedoMapScale = 0` makes detail color neutral, `_BumpMap` remains null, and the original fabric normal occupies `_DetailNormalMap` at strengths 0.23 / 0.21 / 0.19. `_DETAIL_SCALED` is enabled only on the three fabric materials.

Installed URP 17.6.0 package `com.unity.render-pipelines.universal@b9a66914c09e` supports this detail-only configuration. `LitInput.hlsl` lines 280–283 derives detail UV from transformed base UV. `LitForwardPass.hlsl` line 15, `LitGBufferPass.hlsl` line 18 and `LitDepthNormalsPass.hlsl` line 17 provide tangent varyings for `_DETAIL` independently of `_NORMALMAP`; their normal transformation branches likewise accept either keyword. `BaseShaderGUI.cs` line 961 clears `_NORMALMAP` when `_BumpMap` is null, while `LitDetailGUI.cs` lines 68–71 chooses `_DETAIL_SCALED` for a detail normal with scale other than one. The helper follows the public base/Lit validation and the same detail keyword rules. It does not force a `_NORMALMAP` keyword that the material Inspector would clear.
